# Menge-Bibel Farbig

> This repository is the working environment for developers and AI coding
> agents contributing to the **Menge-Bibel Farbig** project.  
> **Human readers looking for the website please go here:  
> → https://christian50907.github.io/menge-bibel-farbig/**

---

The project presents the New Testament (Menge Bible translation, 1926)
as a static website with color-coded annotations:

- 🔴 **Red** — direct words and speech of Jesus
- 🟢 **Green** — quotations and references to the Old Testament
